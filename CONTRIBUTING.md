# Contributing

Thank you for your interest in Product Decision Notebook.

This is an early-stage project. Clear bug reports and practical usability feedback are especially helpful.

## Before contributing

1. Check existing GitHub Issues to avoid duplicates.
2. For a substantial change, open an issue first to discuss the problem and proposed solution.
3. Keep changes focused and explain the user problem they address.

## Reporting a bug

Please include:
- What you expected to happen.
- What actually happened.
- Steps to reproduce the issue.
- Browser and device information.
- Screenshots, if useful (avoid sharing private data).

## Pull requests

- Keep pull requests small and focused.
- Explain the problem and the change.
- Test the affected workflow manually.
- Check desktop and mobile layouts when changing the interface.
- Do not introduce frameworks or dependencies without discussing the trade-off first.

## Development

The app uses plain HTML, CSS and JavaScript. Open `index.html` in a browser or run a local server from the project directory. No package installation is needed.
